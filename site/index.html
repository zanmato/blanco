A lightweight cross platform SQL editor

Blanco runs on Linux, macOS and Windows. Run the statement under the cursor, edit results in place, and write scripts in JavaScript.

Tab based editing

Each tab has its own connection, results and terminal.

Inline editing

Results from a single table with a primary key can be edited in place. Press Enter to edit a cell and Tab to move to the next one.

Changed cells are highlighted until you apply them. All changes are committed in one transaction.

Scripting

Script tabs run JavaScript against the tab's connection with db.query, db.execute and db.transaction. Use db.display to show an array of objects in the results grid.

Scripts run in a sandboxed QuickJS runtime on a separate thread.

Terminal

Press Ctrl ` to open a terminal below the editor. Each tab has its own shell.

Start claude or opencode in it. The shell opens in a workspace where Blanco's MCP server is already configured, so the agent can read and edit the tab it was started from.

Snippets

Save queries and scripts you use often as snippets, organized in folders.

Double click a snippet to open it, or copy it from the context menu.

Features

Editor
Schema aware completion, formatting and linting for SQL, plus command completion and highlighting for Redis.
Running
Run the statement under the cursor or the selection. Bind parameters are prompted for, and every run is saved to the history.
Results
Filter rows, copy or export as CSV, TSV, JSON, SQL or Markdown, show results as a chart, and look up foreign keys.
Explain
EXPLAIN output for PostgreSQL, MySQL and SQLite shown as a plan tree, with time bars for the slow nodes.
Schema
Schema tree with filter and table sizes, table structure, object DDL and an ER diagram. Rename, truncate and drop from the tree.
Import
Import CSV and JSON (array or NDJSON) with column mapping and conflict handling, in one transaction.
Safety
Read only connections, and a confirmation before writes to connections tagged PROD.
Connections
SSH tunnels with known_hosts verification and TLS. Passwords are stored in the OS keychain.
