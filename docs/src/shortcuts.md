# Keyboard shortcuts

Every shortcut can be changed on the **Keybindings** page in Settings. Click a
shortcut and press the new keys. Blanco warns when two actions share keys.
Changes apply after a restart. Actions with no default shortcut can be given
one there too.

## Query

| Action | Linux and Windows | macOS |
| --- | --- | --- |
| Run current statement | <kbd>Ctrl+Enter</kbd> | <kbd>Cmd+Enter</kbd> |
| Explain query | <kbd>Ctrl+E</kbd> | <kbd>Cmd+E</kbd> |
| Explain analyze query | <kbd>Ctrl+Shift+E</kbd> | <kbd>Cmd+Shift+E</kbd> |
| Cancel running query | <kbd>Ctrl+.</kbd> | <kbd>Cmd+.</kbd> |
| Format SQL | <kbd>Shift+Alt+F</kbd> | <kbd>Shift+Option+F</kbd> |
| Upper case keywords | <kbd>Shift+Alt+U</kbd> | <kbd>Shift+Option+U</kbd> |
| Lower case keywords | <kbd>Shift+Alt+L</kbd> | <kbd>Shift+Option+L</kbd> |

## Fixed keys

These can't be changed.

| Where | Keys | Does |
| --- | --- | --- |
| Editor | <kbd>Ctrl+F</kbd> | Find and replace |
| Editor | <kbd>Alt</kbd> click | Add a cursor |
| Editor | <kbd>Ctrl+Alt+Up</kbd>, <kbd>Ctrl+Alt+Down</kbd> | Add a cursor above or below (<kbd>Cmd+Option</kbd> on macOS) |
| Editor | <kbd>Esc</kbd> | Back to one cursor |
| Grid | <kbd>Enter</kbd>, <kbd>F2</kbd> | Edit the cell |
| Grid | <kbd>Tab</kbd> | Next cell while editing |
| Grid | <kbd>Shift</kbd> click a header | Sort by another column |
| Filter bar | <kbd>Enter</kbd> | Apply |
