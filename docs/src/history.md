# Query history

Every query you run is saved, with its connection, when it ran, how long it
took and whether it failed. Open the **History** panel in the sidebar to see
them.

<img class="screenshot-light" src="images/history-latte.webp" alt="The history panel listing recent queries with their timings">
<img class="screenshot-dark" src="images/history-mocha.webp" alt="">
</figure>

- Type in the search field to find a query.
- Double click an entry to insert it into the current query tab.
- Hover an entry to copy or delete it.
- **Clear** removes all history.

Settings sets how many entries are kept.
