# Blanco

Blanco is a SQL editor and database client for Linux, macOS and Windows. It
connects to PostgreSQL, MySQL, MariaDB, SQLite, DuckDB, SQL Server, ClickHouse
and Redis.

These pages describe what Blanco does and where to find it. Start with
[Installing](install.md) and [Connections](connections.md), or jump to a topic
from the list on the left.

Shortcuts are written as they are on Linux and Windows. On macOS, read
<kbd>Ctrl</kbd> as <kbd>Cmd</kbd> unless a page says otherwise. Every
shortcut can be changed, see [Keyboard shortcuts](shortcuts.md).

Found a mistake, or something missing? [Open an
issue](https://github.com/zanmato/blanco/issues) or use the edit link at the
top of each page.
